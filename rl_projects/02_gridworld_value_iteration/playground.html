Bellman Playground

Run the Bellman equation yourself. Green squares are good, red are bad, arrows are the current best move.

Try this
  1. In Value iteration, press "One Bellman sweep" a few times. Watch value spread backwards from the +1 goal, one square per sweep.
  2. Click any square. The panel shows the Bellman optimality equation computed for that square with real numbers.
  3. Drop γ to 0.5. The agent becomes short-sighted and values near the start barely move above the step cost.
  4. Switch to Q-learning. The agent doesn't know the map. Train 1 episode at a time at first and see how little it learns; then train 100. Set ε to 0 from the start (after a reset) and notice it can get stuck never discovering the goal.

Rules of this world: start at S, +1 for reaching the goal, −1 for the pit, −0.04 for every other step (so wandering costs a little). Walking into a wall or the edge leaves you where you are.
