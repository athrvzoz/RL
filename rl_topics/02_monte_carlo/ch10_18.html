12Off-policy: learning from others' games

Real output of python off_policy.py. Intuition only, with light maths.

The question: how good is the state (sum 13, dealer shows 2, usable ace) if I play "stick on 20+" (my target policy π)? But I have no games of my own. I only have games played by someone pressing random buttons (the behaviour policy b: hit or stick, 50/50).

The trick: re-weight each game

A random game that happens to look like something I would play is useful evidence. A game where the random player did something I would never do tells me nothing about my policy. The weight is called the importance-sampling ratio:

ρ  =  product over the moves of   π(a|s) / b(a|s)

    my policy would ALSO choose a:   π = 1,  b = 0.5   →  factor 1 / 0.5 = 2
    my policy would NEVER choose a:  π = 0             →  factor 0  (the whole game counts 0)

Five real random games

game 1: 13:hit, 13:hit        result G = −1   ρ = 2 × 2 = 4   (I'd hit too, both times)
game 2: 13:hit, 15:stick      result G = −1   ρ = 0           (I'd never stick on 15)
game 3: 13:stick              result G = +1   ρ = 0           (I'd never stick on 13)
game 4: 13:stick              result G = +1   ρ = 0
game 5: 13:stick              result G = −1   ρ = 0

Only game 1 looks like my policy, and it counts 4 times as much, because a random player follows my policy for two moves only 1 time in 4 (0.5 × 0.5).

Two ways to average

ordinary IS:   V = Σ ρ·G / (number of games)          unbiased, but can be wild
weighted IS:   V = Σ ρ·G / Σ ρ                        slightly biased, much calmer
Random games usedordinary IS errorweighted IS error
101.2090.540

True value (from playing "stick on 20+" itself 100,000 times): −0.281 (Sutton & Barto report −0.277). After 1,000 random games both estimates average about −0.26.

Connect it to Q-learning

Q-learning is also off-policy (it explores but learns about the greedy policy), yet it needs no ratios. Its target uses max Q[s2], a guess about what the greedy policy would do next, instead of the real rest of the game. Monte Carlo uses the real rest of the game, which was played by the explorer, so it must re-weight. That's one more reason TD-style methods became so popular.

13Real-world problems

Monte Carlo fits whenever the result only becomes clear at the end, and episodes really do end.

When to reach for Monte Carlo

✔ Episodes are fairly short and always finish. ✔ You can't trust step-by-step guesses (the state doesn't capture everything). ✔ You have a simulator you can run many times. ✘ Avoid it for never-ending tasks, or very long episodes where waiting is costly.

1 · A sales call script

Statestage of the call (greeting / needs / offer / objection), customer mood (estimated), offer already made?
Actionask a question / present offer A / present offer B / give a discount / end the call politely
Reward0 during the call; at the end: +profit if the customer buys, 0 if not; small −1 for very long calls
Episodeone call (a few minutes, always ends)
Why MCWhether a step was good is only known at the end (sale or not). The average of final results per (stage, action) is exactly what MC computes.
PitfallCustomers differ a lot: big variance, so you need many calls. You could use off-policy MC (importance sampling) to evaluate a new script from recorded calls made with the old script.

2 · Choosing a treatment plan in a simulated patient

Stateweek of treatment, measured symptoms band, side-effect level
Actioncontinue dose / increase / decrease / switch drug
Rewardat the end of the course: +10 if recovered, −10 if not, minus side-effect penalties
Episodeone full treatment course
Why MCOutcomes arrive at the end; researchers evaluate dosing rules in simulated patients first. MC evaluates a fixed rule by averaging outcomes, with no bootstrapped guesses about half-finished treatments.
PitfallNever learn by exploring on real patients. Real medical decisions need clinical trials and doctors. This is a "could be used for" in research simulations only.

3 · Game AI evaluated by self-play

Statethe board position
Actiona legal move
Reward+1 win, 0 draw, −1 loss, only at the end
Why MC"Play the game to the end many times and average the result" is exactly how Monte Carlo Tree Search judges positions, the planning method in booklet 08 (used in AlphaGo).

4 · Evaluating an ad campaign rule

State = user's journey stage; action = which ad to show; reward = purchase at the end of a session. You often have logs from the old rule. Off-policy MC with importance sampling estimates how a new rule would have done, before risking money on it. The same weighting idea (ρ) is used in practice for "offline evaluation" of recommendation and ad systems.

15Clearing up the confusions

Short, correct answers to common beginner questions.

Does Q-learning wait for the end and update backwards?

No. That's Monte Carlo. Q-learning updates after every step using its guess of the next state.

Why walk backwards? Couldn't we go forwards?

You could, but backwards is efficient: G at step t = rt+1 + γ·(G at step t+1). Walking backwards needs one multiply and one add per step.

Does Monte Carlo use the Bellman equation?

Not as an update rule. It never plugs in a guess of the next state. But the values it converges to do satisfy Bellman's equation, because they are the true averages.

How is this the same as my bandit's Q += (r − Q)/N?

It is the same incremental mean. In the bandit each "game" was one pull; here each (state, action) collects the returns G of the games that passed through it.

Why do we still need exploration?

If the agent never tries "hit on 13 vs dealer 2", it never gets a return for it and never learns its value. With ε = 0.01, 10 states never tried one action.

First-visit or every-visit: which is right?

Both converge to the true value. First-visit uses only the first time a state appears in a game; every-visit uses all of them. In Blackjack a state can't repeat (your sum only goes up, or the ace changes), so they're identical there.

Is Monte Carlo slower than TD?

Often, but not always. On Blackjack (1–3 moves per game) they're similar. On long games TD usually wins because its targets are less noisy (chapter 11).

What does "unbiased" mean here?

On average, the MC target equals the true value (0.502 vs 0.5). TD targets can be systematically off while the guesses are still wrong.

Can Monte Carlo work if the game never ends?

No. G is the total until the end. For never-ending tasks, use TD.

Why is the importance ratio 4 in game 1?

Two moves, each with π/b = 1/0.5 = 2. 2 × 2 = 4. A random player follows my policy twice in a row only 1 time in 4, so when it does, that game stands in for four.

Does the learned policy beat the casino?

No. Best learned average −0.040 per game: you still lose 4 paise per rupee bet on average. RL finds the best way to play; it can't change the game's odds.

Why do some learned chart cells look "wrong" compared to the textbook?

Near-ties. For (sum 12, dealer 2) Q(stick) = −0.300 vs Q(hit) = −0.301: a coin flip of noise decides the letter. More games shrink the noise.

Monte Carlo control 
Q = 0, N = 0 for every (s, a)

  play the WHOLE game with ε-greedy(Q),
    recording (s, a, r) at each step
  G = 0

Key formulas 
Return:   G_t = r_t+1 + γ·G_t+1
Average:  Q += (G − Q) / N
TD(0):    V += α(r + γV(s′) − V)
Ratio:    ρ = Π π(a|s) / b(a|s)
Ord. IS:  V = Σρ·G / n
Wtd. IS:  V = Σρ·G / Σρ
Four sentences to remember
  1. Monte Carlo plays the whole game, then walks backwards giving every visited (state, action) the real return G.
  2. Its value is just an average of returns, the same incremental mean as your bandit.
  3. No guesses means no bias, but one game's luck makes the target noisy; TD trades a little bias for much less noise.
  4. Learning from someone else's games needs importance-sampling weights ρ = Π π/b.

18Answers to the practice problems

  1. Backwards: step 3: G = 5. Step 2: G = 0 + 0.9 × 5 = 4.5. Step 1: G = 0 + 0.9 × 4.5 = 4.05.
  2. N becomes 5: V = 0.2 + (−1 − 0.2)/5 = 0.2 − 0.24 = −0.04.
  3. V = 0.2 + 0.1 × (−1.2) = 0.08. Here 1/N = 0.2 > α = 0.1, so the 1/N rule reacts more. Later, when N is large, constant α reacts more (and keeps adapting if the world changes).
  4. Returns: from the first X: 2 + 0 + 1 = 3; from Y: 1; from the second X: 1. First-visit sample for V(X): 3. Every-visit samples: 3 and 1 (average 2).

  8. TD's target trusts V(s′), and if the state hides important information, V(s′) mixes up different situations and is systematically wrong. MC uses the real final result, which already "knows" what happened.
  9. TD. 7,000 steps per episode means MC learns nothing for 2 hours and then gets one very noisy return. TD learns after every step.
  10. A reasonable prediction: slightly worse or about the same. Less exploration means fewer tries of rarely chosen actions (experiment B: ε = 0.01 left 10 states untested), but the training games are closer to greedy. Run it to check.
