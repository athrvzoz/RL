PART 2 · One REINFORCE update, 2 actions (Left, Right), by hand
================================================================
  logits θ = [1. 0.]  →  π = [L 0.731, R 0.269]
  the agent rolled its dice and got a = Right (only 26.9% likely); return G = 2.0
  ∇log π(Right) = onehot(Right) − π = [0 − 0.731, 1 − 0.269] = [-0.731  0.731]
  step = α·G·∇log π = 0.1·2.0·[-0.731  0.731] = [-0.146  0.146]
  new θ = [0.854 0.146]  →  π = [L 0.670, R 0.330]
  if instead G = -2.0: new θ = [ 1.146 -0.146] → π = [L 0.785, R 0.215]
  if a = Left (likely) with G = 2.0: ∇log π(Left) = [ 0.269 -0.269], new π = [L 0.752, R 0.248]
