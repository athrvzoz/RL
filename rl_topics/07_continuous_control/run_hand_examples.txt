1. Why you can't try every number
======================================================================
  Pendulum torque from -2 to +2 in steps of 0.1: 41 choices (fine for DQN)
  robot with 2 joints, 41 choices each: 41 ** 2 = 1,681 actions
  robot with 3 joints, 41 choices each: 41 ** 3 = 68,921 actions
  robot with 7 joints, 41 choices each: 41 ** 7 = 194,754,273,881 actions
  ...and even 0.1 is too coarse for a motor: 0.73 and 0.74 are different torques.

2. Soft (Polyak) target update, tau = 0.005
======================================================================
  online weight 0.8, target weight 0.5
  one step: (1 - 0.005) × 0.5 + 0.005 × 0.8 = 0.5015
    after    1 steps: target = 0.5015
    after   10 steps: target = 0.5147
    after  100 steps: target = 0.6183
    after  138 steps: target = 0.6498
    after  500 steps: target = 0.7755
    after 1000 steps: target = 0.7980
  the gap halves every ln(0.5)/ln(0.995) = 138 steps
  bigger tau = 0.1 (easier by hand):  0.5300  0.5570  0.5813

======================================================================

  step 1: θ=0.8000  a=0.8000  Q=3.5600  ∂Q/∂a=2.4000  ∂a/∂θ=1.0  ∂Q/∂θ=2.4000  ->  θ_new = θ + 0.1×2.4000 = 1.0400
  step 2: θ=1.0400  a=1.0400  Q=4.0784  ∂Q/∂a=1.9200  ∂a/∂θ=1.0  ∂Q/∂θ=1.9200  ->  θ_new = θ + 0.1×1.9200 = 1.2320
  step 3: θ=1.2320  a=1.2320  Q=4.4102  ∂Q/∂a=1.5360  ∂a/∂θ=1.0  ∂Q/∂θ=1.5360  ->  θ_new = θ + 0.1×1.5360 = 1.3856

5. Over-estimation: the max of noisy guesses is too high
======================================================================
  true value of every action: 10.0
  critic 1 guesses [10.8, 9.5, 10.2, 9.1, 11.3]  ->  max = 11.3 (action 5), too high by 1.3
  critic 2 at that action: 9.8   ->  min(11.3, 9.8) = 9.8
  simulation, 100,000 trials, 10 actions, true value 0, each guess off by N(0,1):
    one critic, max          : average error +1.540   (always too optimistic)
    TD3, min of twin critics : average error -0.049
  bootstrapping feeds this error into the next target, so it adds up step after step;
  with γ = 0.99 one step of +1.54 can grow toward 1.54/(1-0.99) = 154

6. TD3 target policy smoothing
======================================================================
  μ_target(s2) = 1.6, noise drawn +0.3 -> clip to ±1.0 -> +0.3 -> a2 = clip(1.6 +0.3) = 1.9
  μ_target(s2) = 1.6, noise drawn -1.4 -> clip to ±1.0 -> -1.0 -> a2 = clip(1.6 -1.0) = 0.6
  (noise std = 0.2 × 2 = 0.4, clip = 0.5 × 2 = 1.0, torque limit ±2.0)

7. SAC: reparameterisation + tanh squash
======================================================================
  mean 0.3, σ 0.5, ε = 0.8:  u = 0.3 + 0.5 × 0.8 = 0.700
  tanh(0.700) = 0.6044  ->  torque = 2 × 0.6044 = 1.2087
  ∂torque/∂mean = 2·(1 - tanh²) = 1.2695    ∂torque/∂σ = 2·(1 - tanh²)·ε = 1.0156
  log N(u; 0.3, 0.5) = -½ε² - ln σ - ½ln(2π) = -0.320 + 0.6931 - 0.9189 = -0.5458
  squash correction: - ln(1 - tanh²) = - ln(0.6347) = +0.4545
  log π(a|s) = -0.5458 +0.4545 = -0.0913
