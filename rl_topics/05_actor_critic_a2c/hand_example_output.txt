EXAMPLE 1  Better than expected (delta > 0), actor starts 50/50
======================================================================
  GIVEN    preferences h = [0.0000, 0.0000]   ->  pi = [0.5000, 0.5000]
           critic V(s) = 0.5, V(s') = 0.6,  reward r = 1.0,  gamma = 0.9
           action taken: right  (it had probability 0.5000)

  STEP 1   target = r + gamma*V(s') = 1.0 + 0.9*0.6 = 1.5400
           delta  = target - V(s)   = 1.5400 - 0.5 = +1.0400

  STEP 2   critic: V(s) <- 0.5 + 0.1*(+1.0400) = 0.6040

  STEP 3   grad log pi(right) = one_hot - pi = [-0.5000, +0.5000]
           h <- h + alpha*delta*grad = [-0.0520, 0.0520]
           new pi = [0.4740, 0.5260]   pi(right): 0.5000 -> 0.5260  (+0.0260)

  CHECK    autograd gives h = [-0.0520, 0.0520], V = 0.6040   -> MATCHES
