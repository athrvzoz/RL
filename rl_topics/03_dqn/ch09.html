Best network, 100 test games with no exploration: average score 472.9 (max 500)

What to notice (honestly)

  • It learned fast: after only 143 games (2,500 steps) the greedy test already scored 431. A random player scores about 22.
  • Then it wobbled: test scores swung between 110 and 360 for the rest of the run. This is the famous instability of DQN: improving Q for some states disturbs others (chapter 05's shared weights), and the buffer fills with "good" states so it forgets what danger looks like.
  • Keeping the best network matters: the saved best version averages 472.9 out of 500 over 100 fresh games. Real DQN projects always keep checkpoints, for exactly this reason.
  • The loss is not a scoreboard: it doesn't go down steadily, because the targets keep moving. Judge an RL agent by its score, not by its loss.

Looking inside the best network

state                       Q(left)   Q(right)   choice
balanced, still               3.2       3.2      push RIGHT  (a near-tie)
pole leaning RIGHT            3.1       3.2      push RIGHT  ✓ like balancing a stick
pole leaning LEFT             3.2       3.2      push LEFT   ✓
pole falling right fast       2.6       2.6      push RIGHT  ✓
almost fallen right           2.7       2.8      push RIGHT  ✓
Two lessons in one table
  • It discovered the human rule "push toward the side the pole leans", without anyone telling it. Nobody wrote this rule into the code.
  • The values are far from "true": about 3, while a perfect player's true Q is close to 100 (= 1/(1 − 0.99)). The best network came from step 2,500, very early, before the values had grown. It still plays well because choosing an action only needs the order of Q(left) and Q(right) to be right, not their size. Nearly-falling states correctly get lower values (2.6–2.8) than calm ones (3.2).
